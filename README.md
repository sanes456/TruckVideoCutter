# 🚛 Truck & Military Video Cutter (4K AI Drone & Top-Down Engine)

Автоматизированный инструмент для глубокого поиска, скачивания, нарезки, ИИ-фильтрации (YOLOv8) и автосортировки видео с грузовиками, наземной техникой и дронами.

---

## 🌟 Ключевые возможности

- 🎯 **Умная трехуровневая автосортировка клипов**:
  - 📁 **`грузовики/`** — фуры, тягачи с прицепами, самосвалы с породой, лесовозы, автопоезда, тяжеловозы и негабаритные перевозки.
  - 📁 **`наземная/`** — военная наземная техника (танки, БМП, БТР, военные колонны, РСЗО, артиллерия).
  - 📁 **`воздушная/`** — дроны, БПЛА, FPV-дроны, квадрокоптеры, барражирующие боеприпасы и аэросъемка.
- 🤖 **Нейросетевая фильтрация YOLOv8 (imgsz=960)**:
  - Детекция техники с ракурса «вид сверху» (Top-Down / Drone / Aerial).
  - Подтверждение наличия грузовиков, кузовов, грузов, бронетехники или дронов перед нарезкой.
  - Отсеивание нерелевантных кадров и симуляторов (BeamNG, GTA, игры).
- ✂️ **Адаптивная нарезка и анти-вотермарк зум**:
  - Экспорт в **9:16 (1080x1920)** для YouTube Shorts, TikTok, Instagram Reels.
  - Экспорт в **16:9 (1920x1080 Full HD)** для стандартного YouTube.
  - Экспорт в оба формата одновременно (подпапки `9_16/` и `16_9/`).
  - Опциональное удаление аудиодорожки (`-an`) для чистого видеоряда.
- 🔍 **Глубокий поиск YouTube & Стоки**:
  - Поиск по десяткам оптимизированных запросов 4K Top-Down / Drone.
  - Поддержка стоковых платформ Pexels и Pixabay по API.
  - Обход антибот-защиты YouTube и поддержка `cookies.txt` (Netscape format).
- 🧠 **Память и самообучение ИИ**:
  - База `downloaded_history.json` исключает повторную обработку одних и тех же роликов.
  - Обучение на основе успешных детекций для приоритизации лучших поисковых каналов.

## 🚀 Быстрый запуск (Windows)

Самый простой способ — запустить скрипт быстрой автоматической настройки:

1. Запустите **`start.bat`**.
2. Скрипт сам проверит наличие Python (или установит его через winget при необходимости), создаст виртуальное окружение `.venv`, установит все библиотеки и запустит приложение.

---

## 🛠 Ручная установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/sanes456/TruckVideoCutter.git
cd TruckVideoCutter
```

### 2. Создание виртуального окружения
```bash
python -m venv .venv
# Активация:
# Windows (cmd/PowerShell):
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. FFmpeg
Убедитесь, что `ffmpeg` и `ffprobe` доступны в системе (в PATH) или помещены в папку `bin/` проекта (`bin/ffmpeg.exe`, `bin/ffprobe.exe`).

### 5. Запуск
```bash
python main.py
```
